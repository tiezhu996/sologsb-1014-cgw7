# 格致 · 数学证明步骤编写与检查工具

一个完全在浏览器运行的数学证明工作台。使用步骤、引用和推理规则组织证明，实时检查结构与符号，并保留版本快照。

## 功能

- 逐步录入前提、推导和结论，选择推理规则并维护步骤引用。
- **规则包引用**：规则包声明每条规则的前提槽、结论槽与符号环境；步骤必须绑定槽位才能通过检查。
  - 引用时固定当时的规则内容（快照），规则包之后更新不改变历史依据。
  - 同名规则跨包保留各自来源（如欧氏/双曲几何各自的“平行公理”）；互斥规则包不能在同一证明中混用。
  - 规则包更新后，受影响步骤立即失效并标记为“待复核”，原槽位绑定保留，逐条确认后才能导出。
  - 旧证明只有规则名称时，自动按名称生成“待确认”映射以兼容：唯一匹配预填来源与槽位，多个同名规则需手动选择来源；重开后来源与状态仍保留。
  - 存在待确认/待复核绑定时禁止导出 Markdown / LaTeX。
- 检查未定义符号、缺失引用、循环引用、槽位未绑定、冲突规则包混用和未证明目标。
- 为步骤记录旁注、反例和替代分支。
- 公式快捷输入、KaTeX 实时渲染、原生拖拽排序与键盘导航。
- 文档级撤销/重做，`localStorage` 自动保存，多版本文档管理。
- 保存版本快照并进行逐步差异比较。
- 导出 Markdown 或 LaTeX 证明稿。

## 规则包

内置「初等代数规则包」「欧氏几何公理包」「双曲几何公理包」。在左栏“规则包库”中可以：

- 查看规则的前提槽、结论槽与符号环境声明；
- 导出规则包 JSON、通过 **⇪** 导入或更新规则包（同 `id` 覆盖，更新后引用自动标记待复核）；
- 内置包提供“模拟发布修订”按钮，便于演示引用失效与复核流程。

## 本地开发

```bash
npm install
npm run dev
```

浏览器打开终端输出的开发地址。数据保存在当前浏览器的 `localStorage` 中。

## 生产构建

```bash
npm run build
npm run preview
```

构建产物位于 `dist/`。

## 规则包引用逻辑测试

```bash
npm test
```

覆盖旧证明兼容映射、槽位校验、同名跨包来源、冲突包混用拦截、规则包更新失效与逐条复核、导出门控等场景。

## 键盘操作

| 快捷键 | 操作 |
| --- | --- |
| `Ctrl/Cmd + Enter` | 添加推导步骤 |
| `Ctrl/Cmd + Shift + Enter` | 添加结论步骤 |
| `Alt + ↑ / ↓` | 切换当前步骤 |
| `Ctrl/Cmd + Z` | 撤销 |
| `Ctrl/Cmd + Shift + Z` 或 `Ctrl/Cmd + Y` | 重做 |
| `Ctrl/Cmd + S` | 立即保存 |
| `Delete` | 删除当前步骤（编辑框外） |

## Docker

镜像内由 nginx 监听容器端口 `80`，不包含或硬编码宿主端口。

```bash
docker build -t math-proof-editor .
docker run --rm -p 10014:80 math-proof-editor
```

宿主端口 `10014` 仅用于本地运行示例，实际编排端口以根端口表为准。
