# 格致 · 数学证明步骤编写与检查工具

一个完全在浏览器运行的数学证明工作台。使用步骤、引用和推理规则组织证明，实时检查结构与符号，并保留版本快照。

## 功能

- 逐步录入前提、推导和结论，选择推理规则并维护步骤引用。
- 规则包引用：规则包声明前提槽、结论槽与符号环境，步骤绑定槽位后检查才通过。
- 绑定固定当时的规则内容并保留来源；同名跨包规则互不混淆，互斥包不能混用。
- 规则包更新后受影响步骤立即标为待复核，原绑定保留，逐条确认后才能导出。
- 旧证明缺少绑定时按规则名生成待确认映射，重开后来源与状态保持不变。
- 检查未定义符号、缺失引用、循环引用和未证明目标。
- 为步骤记录旁注、反例和替代分支。
- 公式快捷输入、KaTeX 实时渲染、原生拖拽排序与键盘导航。
- 文档级撤销/重做，`localStorage` 自动保存，多版本文档管理。
- 保存版本快照并进行逐步差异比较。
- 导出 Markdown 或 LaTeX 证明稿（含规则来源与槽位绑定）。

## 规则包

规则包是推理规则的集合，每条规则声明**前提槽**、**结论槽**与**符号环境**：

```json
{
  "id": "pkg-algebra",
  "name": "初等代数公理",
  "version": "1.1",
  "conflictsWith": ["pkg-methods-intuitionistic"],
  "rules": [
    {
      "id": "rule-distribute",
      "name": "分配律",
      "statement": "$a(b+c)=ab+ac$",
      "premiseSlots": [{ "id": "product", "label": "乘积式" }],
      "conclusionSlots": [{ "id": "sum", "label": "展开和" }],
      "symbols": { "a": "任意项", "b": "任意项", "c": "任意项" }
    }
  ]
}
```

- 步骤在检查器中选择「包 / 规则」完成绑定，并把每个前提槽绑定到引用的步骤；结论槽固定指向本步骤。
- 绑定固定当时的规则内容（快照），包更新后内容不一致的步骤立即标为**待复核**，原绑定保留，逐条确认后才能导出。
- 同名规则可来自不同包，绑定始终记录来源；`conflictsWith` 声明互斥的包不能在同一证明中混用。
- 通过左侧「规则包」面板的 `+` 导入 JSON；包 id 相同视为更新。面板中提供三个示例包，分别演示同名规则、互斥包与包更新。
- 旧版本保存的证明缺少绑定，打开时按规则名自动生成**待确认**映射，来源与状态会持久保存。

## 本地开发

```bash
npm install
npm run dev
```

浏览器打开终端输出的开发地址。数据保存在当前浏览器的 `localStorage` 中。

## 生产构建

```bash
npm run build
npm run preview
```

构建产物位于 `dist/`。

## 键盘操作

| 快捷键 | 操作 |
| --- | --- |
| `Ctrl/Cmd + Enter` | 添加推导步骤 |
| `Ctrl/Cmd + Shift + Enter` | 添加结论步骤 |
| `Alt + ↑ / ↓` | 切换当前步骤 |
| `Ctrl/Cmd + Z` | 撤销 |
| `Ctrl/Cmd + Shift + Z` 或 `Ctrl/Cmd + Y` | 重做 |
| `Ctrl/Cmd + S` | 立即保存 |
| `Delete` | 删除当前步骤（编辑框外） |

## Docker

镜像内由 nginx 监听容器端口 `80`，不包含或硬编码宿主端口。

```bash
docker build -t math-proof-editor .
docker run --rm -p 10014:80 math-proof-editor
```

宿主端口 `10014` 仅用于本地运行示例，实际编排端口以根端口表为准。
